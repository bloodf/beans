Support

Beans runs AI bots on your own computers. Phones and tablets pair with that account to chat with them.

Get help

Read the Beans documentation or report a reproducible software issue in GitHub Issues. Use support@usebeans.app for private support and privacy questions.

Include the app version, operating system, and steps to reproduce a problem. Keep private chat content, backup phrases, API keys, access tokens, and service-account files out of public issue reports.

Account and device controls

You can unpair devices in Settings → Devices. On a paired Mac, Settings → Advanced → Delete Account requests deletion of the account's data on its relay. Manage any copies, exports, backups, and data held by AI providers separately.

Before switching Android installation channels

Google Play and the GitHub APK can use different signing certificates. Keep a backup of your account recovery information and confirm upgrade compatibility before changing channels.

Read the privacy page for details about local data, encrypted relay sync, AI providers, and notifications.
